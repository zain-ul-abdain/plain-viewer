2. Microsoft Edge WebView2 Runtime

Plain Viewer shows PDF, Word, Excel and PowerPoint files with the Microsoft Edge WebView2 Runtime, which is part of Windows 11. This smaller installer does not contain it. If the runtime is missing on this PC, setup tells you at the end: text, CSV and Markdown files still open, and the full installer (the one without "without-webview2" in its name) adds the runtime.
